# Aether Vault 💎
> **Minimalist Fintech, SaaS Cashflow & Subscription Tracker for Android**

Built with modern **Native Kotlin**, **Jetpack Compose (BOM 2024)**, and **Hardware Keystore AES-256 GCM encryption**. Zero third-party telemetry, 100% offline-first.

---

## 🌟 Key Architecture & Highlights
- **Nordic Dark Fintech UI**: Minimalist Obsidian Graphite layout with Mint Green & Electric Indigo accents.
- **Custom Canvas Analytics**: Smooth high-performance category intensity bars without heavy charting bloat.
- **Recurring SaaS Manager**: Clear separation of one-time transactions and monthly recurring overhead.
- **Bank-Grade Data Protection**: Encrypted using Android Jetpack Security's `EncryptedSharedPreferences`.
- **Automated CI/CD**: Signed production APKs compiled directly via GitHub Actions.
